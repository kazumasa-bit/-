# 市場ノート（外の変化を吸う台帳）

> 層3（記録）。無制限に溜めてよい。
> **すべての行に賞味期限を付ける。** 期限切れの行は月次抽出会で再確認します。
> 古い相場・古い法令を前提に判断し続けることが、実務では一番高くつきます。

## 書き方

| ID | 観測日 | 観測した事実 | 出典 | **賞味期限** | うちへの含意（これが本体） | 影響するID | 状態 |
|---|---|---|---|---|---|---|---|
| M-0001 |  |  |  |  |  |  | 有効 |

**状態：** 有効 / 要再確認（期限切れ）/ 失効

### 4つの注意

1. **「事実」と「含意」を分けて書く。** 事実だけ集めても判断は変わりません。
   「うちにとって何を意味するか」まで書いて初めて使えます
2. **影響するIDを必ず書く。** どのカードに効く情報なのか繋がっていないと、誰も見に来ません
3. **AIに調べさせた情報は出典必須。** 出典のない数字は層2に昇格させません
4. **期限は短めに。** 相場は6ヶ月、競合は3ヶ月、法令は改正日、が目安
