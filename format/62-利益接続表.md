# 利益接続表（すべてを利益に繋ぐ）

> **すべてのテーマ・全ステップは、3つの出口のどれかに繋がっていなければなりません。**
> 繋がらないものは、やりません。これで「やった感のある無駄仕事」が構造的に排除されます。

---

## 3つの出口

| 出口 | 意味 | 測り方 | 注意 |
|---|---|---|---|
| **① 売上を上げる** | 客数 × 単価 × 頻度 のどれかが増える | 円／月 | どの変数に効くのかを明示する |
| **② コストを下げる** | 費用・ロス・手戻りが減る | 円／月 | 一時的か継続的かを区別する |
| **③ 時間を空ける** | 人の時間が空く | 時間／月 × 時給 = 円／月 | **必ず円に換算する** |

### ③が一番よく使われ、一番ごまかされます

「楽になった」で終わらせると、**空いた時間は消えます。**
空いた時間を何に使うかまで書いて、初めて利益になります。

```
❌ シフト作成が楽になった
⭕ シフト作成 月16時間 → 8時間。空いた8時間で新人同行を月4回実施。
   時給2,000円換算で月1.6万円のコスト削減 ＋ 新人の立ち上がり短縮（②へ再投資）
```

## テーマ別 利益接続表

| テーマID | テーマ名 | 出口 | 想定効果（円/月） | 確からしさ | 効き始め | 実測（3ヶ月後） | 状態 |

| T2 | 店長候補の内部輩出 | ① | 未算定 | 低 | 12ヶ月 | | 進行中 |
| T3 | 食材ロスの削減 | ② | 8万 | 中 | 2ヶ月 | | 起票済 |

**確からしさ：** 高（実績データあり）／中（類似の前例あり）／低（当てずっぽう）

### 見方

- **合計が積み上がっているか**が、このエンジンが機能しているかの答えです
- **「確からしさ:低」が半分を超えていたら要注意。** 願望で計画が組まれています
- **効き始めが6ヶ月超のテーマばかりだと、途中で全部止まります。** 短期のテーマを必ず混ぜてください

## ステップ単位でのチェック

各ステップカードに1行。書けないステップは削ります。

```
S2-1 求人媒体を決める
  → 出口②：採用単価 6万→4万 × 月6名 = 月12万円の削減に効く
```

```
S5-1 入社90日プログラムをつくる
  → 出口②：早期離職1名あたり損失60万 × 年2名減 = 月10万円相当
```

**「必要だから」「当たり前だから」は理由になりません。**
どの出口に、いくら効くのか。当てずっぽうでも数字を置きます。

## 「考える時間」も利益として計上する

決定ゲート（`60-決定ゲート`）でオートパイロット率が上がると、考える時間が減ります。
**これも③として計上します。**

```
2026-10：考える時間 週5時間
2026-12：考える時間 週3時間  → 月8時間の削減 × 時給5,000円 = 月4万円
```

**利益最大化と、考える時間の削減は、同じ表の上で足し算になります。**
どちらか一方だけを追わないための表です。
