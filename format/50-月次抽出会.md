# 月次抽出会（60分の進行台本）

> **ログは溜めるだけでは学習になりません。ルールに昇格させる場が必要です。**
> 月1回・60分。参加者は決裁者1名＋現場1名＋AI。
> ここを飛ばすと、この仕組みは「記録が溜まるだけのフォルダ」になります。

---

## 進行

| # | 時間 | やること | 判定・アウトプット |
|---|---|---|---|
| 1 | 10分 | **メタKPIを見る** | 進化しているか／止まっているか |
| 2 | 15分 | **実績ノートの予測 vs 実測** | 同方向の外れ3回 → **補正係数 C に昇格** |
| 3 | 10分 | **修正ログのR2を確認** | 同じ方向のズレ3回 → **うちらしさカードに昇格** |
| 4 | 10分 | **決定ログの理由を集計** | 偏りが出たら → **判断軸の重み W を更新** |
| 5 | 5分 | **市場ノートの期限切れ確認** | 期限切れ → 再調査 or 失効 |
| 6 | 5分 | **委任レベルの昇降格判定** | DoD2回連続達成 → +1／R1・R2が2回連続 → -1 |
| 7 | 5分 | **層2の棚卸し** | **200行超なら、効いていない行を退役させる** ★飛ばさない |

**事前準備：** AIに「今月の抽出会の材料をまとめて」と頼めば、1〜6の素案が出ます。会議はその判定だけ。

---

## 昇格の基準：3回ルール

> **1回のズレはただの事件。3回繰り返されたものだけがルールになります。**

1回でルール化すると層2が例外だらけになり、AIが何を優先すべきか分からなくなります。
（**例外：法令・安全・金銭事故に関わるものは1回で即ルール化**）

| 回数 | 扱い |
|---|---|
| 1回目 | ログに記録するだけ |
| 2回目 | 「候補」としてマークする |
| 3回目 | **層2に昇格。IDを振る** |

---

## メタKPI（進化しているかを測る5つの数字）

| # | 指標 | 測り方 | 目標 | 今月 | 先月 |
|---|---|---|---|---|---|
| 1 | 一発OK率 | AI出力が修正なしで採用された割合 | 60%以上 | | |
| 2 | **R2発生率** | 全修正のうち「感覚ズレ」の割合 | **下降傾向** | | |
| 3 | 予測誤差 | 予測と実測の平均乖離率 | ±30%以内 | | |
| 4 | 平均委任レベル | 全ステップのレベル平均 | 上昇傾向 | | |
| 5 | 決定までの時間 | 選択肢提示から決定までの日数 | 短縮傾向 | | |

### 数字の読み方（ここが本番）

| 症状 | 意味 | 打ち手 |
|---|---|---|
| **R2発生率が下がらない** | うちらしさカードへの追記が形だけになっている | 追記の文が抽象的すぎないか確認。「＝具体的には」まで書く |
| 予測誤差が縮まらない | 予測が甘い、または実測を取っていない | 予測欄の空欄を許していないか確認 |
| 一発OK率だけ高い | **AIに合わせて人が妥協している可能性** | 却下の理由が減っていないか確認。健全な却下は必要 |
| 委任レベルが上がらない | DoDが曖昧で判定できていない | DoDを測れる形に書き直す |
| すべて横ばい | **抽出会が形骸化している** | 3回ルールの候補が溜まっているか確認 |

## 層2の棚卸し（一番忘れられる工程）

**層2（うちらしさカード＋補正係数C＋重みW＋クセK）の合計を200行以内に保ちます。**

超えていたら、以下の順で退役させます。

1. **3ヶ月以上、一度も参照されなかった行**
2. **もう再現しなくなった補正係数**（例：媒体を変えたら効かなくなった）
3. **より一般的なルールに吸収できる行**（3行を1行にまとめる）

退役した行は削除せず、各カードの「退役」欄に理由付きで移します。

> **なぜ上限が要るのか：** 参照資料が膨れるほど、AIは要点を見失って**逆に劣化します**。
> 「全部覚えさせる」は進化ではありません。**効く形に絞り込むことが進化です。**
