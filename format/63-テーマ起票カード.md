# テーマ起票カード（誰でも10分で新しいテーマを立てる）

> エンジンの入口。**採用でも、シフトでも、原価でも、何を入れても同じ手順で回ります。**
> 10分で書けない設計にはしません。足りない部分はAIが埋めます。

---

## 起票（人が10分で書く）

```
【テーマID】T_        【起票者】        【日付】

■ 困っていること（事実で1〜3行）


■ 放置するとどうなるか


■ 出口はどれか（→ 62-利益接続表）
  □ ①売上が上がる     月      円
  □ ②コストが下がる   月      円
  □ ③時間が空く       月    時間 →  円
     └ 空いた時間で何をするか：

■ 確からしさ    □高（データあり） □中（前例あり） □低（当てずっぽう）
■ 効き始めるまで        ヶ月
■ いつまでに解決したいか

■ 自分で決めていいこと／上長に聞くこと
  決めていい：
  聞く：

■ すでに分かっていること・持っているデータ

■ 過去にやってみたこと（あれば）
```

---

## AIがやること（起票を受けたら、この順で1つずつ）

1. **前例を引く**（★最初にこれをやる）
   層2と過去テーマを検索し、**流用できる前例・補正係数・クセ**を提示する。
   「T1と同型です。前例により3ステップは省略できます」と言えるのが理想
2. **不足情報を質問する**（推測で埋めない。3つまで）
3. **北極星カードの下書き**（KPI・期限・やらないこと）
4. **局面（ST）に分解**（5〜7個。多すぎたらテーマが大きすぎる）
5. **最初の局面だけステップに分解**（全部一度に出さない）
6. **各ステップを決定ゲートで振り分け**（🟢🟡🔴）
7. **🔴のステップだけ選択肢カードを作る**（🟢🟡は前例適用）
8. **やることシート（今週の3つ）を出す**

**8まで出して、初めて「計画ができた」とします。**
「明日、誰が、何をするか」まで落ちていない計画は、計画ではありません。

---

## 起票を受け付けない条件

以下は、AIが起票時に指摘して差し戻します。

| 条件 | なぜ差し戻すか |
|---|---|
| **出口が空欄** | 利益に繋がらないテーマは、やる意味がありません |
| **測り方が決まらない** | 検証できないPDCAは「やりっぱなし」になります |
| **その人が1人で2テーマ以上抱えている** | 増やすと全部止まります |
| **テーマが大きすぎる**（局面が8個以上になる） | 分割を提案します |
| **週3時間を超える計画になる** | 経験上ほぼ止まります（K3） |

## 記入例

```
【テーマID】T1   【起票者】私   【日付】2026-09-03

■ 困っていること
  シフト作成に毎週4時間かかっている。しかも作るのが遅く、希望が反映しきれない

■ 放置するとどうなるか
  店長の休みが取れない。希望が通らない不満が溜まり、離職に繋がる

■ 出口
  ☑ ③時間が空く  月16時間 → 時給2,500円換算で 月4万円
     └ 空いた時間で：新人の同行指導を月4回。早期離職を減らす（→②へ再投資）

■ 確からしさ  ☑高（毎週の実測あり）
■ 効き始めるまで  1ヶ月
■ いつまでに  3ヶ月以内

■ 決めていい：シフトの組み方、使うツール
   聞く：有料ツールの導入、他店舗への展開

■ すでに分かっていること
  過去8週分のシフト実績あり。固定シフトの人が6割、変動が4割

■ 過去にやってみたこと
  スプレッドシートのテンプレ化 → 結局、希望調整の手戻りが減らず効果が薄かった
```
