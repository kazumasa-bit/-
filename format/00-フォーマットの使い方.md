# フォーマットの使い方（最初に読む1枚）

## 1. ファイルの置き方

```
examples/<テーマ名>/
  00-北極星カード.md          ← 1枚だけ
  01-うちらしさカード.md       ← 1枚だけ（育て続ける）
  steps/
    S1-1-〇〇.md              ← ステップ1枚につきファイル1つ
    S2-1-〇〇.md
    ...
  90-決定ログ.md              ← 追記のみ
  91-修正ログ.md              ← 追記のみ
  92-市場ノート.md            ← 追記のみ（賞味期限つき）
  93-実績ノート.md            ← 予測vs実測、補正係数
  94-習熟・委任カード.md       ← 人とAIの分担
  95-判断クセ辞典.md          ← 判断軸の重み
```

**ルール：1ステップ＝1ファイル。** これを守るだけで修正コストが激減します。

## 2. IDの振り方（住所）

| 対象 | 形式 | 例 |
|---|---|---|
| 北極星 | `G+数字` | `G1` |
| 局面 | `ST+数字` | `ST3` |
| ステップ | `S<局面>-<連番>` | `S3-2` |
| 選択肢 | `O<ステップ>-<英字>` | `O3-2-B` |
| 決定 | `D-<4桁連番>` | `D-0007` |
| 実行 | `RUN-<4桁連番>` | `RUN-0007` |
| 修正 | `R-<4桁連番>` | `R-0012` |
| 市場観測 | `M-<4桁連番>` | `M-0003` |
| 補正係数 | `C+数字` | `C1` |
| 判断軸の重み | `W+数字` | `W1` |
| 判断のクセ | `K+数字` | `K2` |
| 失敗DB | `F+数字` | `F1` |

**IDは絶対に使い回さない。** 消したステップのIDも欠番のまま残す（履歴が追えなくなるため）。

## 3. 1周の手順

| # | フェーズ | やること | 担当 |
|---|---|---|---|
| ① | DESIGN | AIに局面分解 → ステップ分解 → 選択肢3案を出させる | AI |
| ② | DECIDE | スタッフが案を選び、理由を1行書く | 人 |
| ③ | DO | 選んだ案を実行する | 現場 |
| ④ | DETECT | ズレを見つけ、R1〜R4のどれか分類する | 人＋AI |
| ⑤ | DIFF | 型に沿って直す。修正ログに残す | AI＋人 |

①→⑤→①… と回します。全ステップがDoDを満たし、担当者を変えて2回連続で回ったら完成。

**②の前に予測を書き、③のあと実測を入れる。** これを飛ばすとAIは学習しません（→ `41-実績ノート`）。

## 3-2. 3つのリズム

| 周期 | やること | 所要 |
|---|---|---|
| **その都度** | 選択肢を出す → 決める → 実行 → ズレたら型を付けて直す | – |
| **週1** | 修正ログを見る。R2の件数、同じステップでのR1の重複を確認 | 5分 |
| **月1** | **抽出会**。ログをルールに昇格させ、層2を棚卸しする（→ `50-月次抽出会`） | 60分 |

**月1の抽出会を飛ばすと、この仕組みは「記録が溜まるだけのフォルダ」になります。**

## 4. AIへの頼み方（そのまま使える言い方）

| したいこと | 言い方 |
|---|---|
| 局面に分けてほしい | 「G1 を局面に分けて。ST番号を振って、各局面のゴールを1文で」 |
| ステップに分けてほしい | 「ST3 をステップに分けて。各ステップは1人が1回で終わる大きさで」 |
| 選択肢がほしい | 「S3-2 の選択肢カードを書いて。3案、5軸採点、推奨1つ、理由つきで」 |
| 実務エラーの修正 | 「S3-2 が **R1**。〇〇の手順が回らない。そのステップだけ直して」 |
| 感覚ズレの修正 | 「S3-2 が **R2**。〇〇がうちっぽくない。うちらしさカードに追記してから直して」 |
| 方向ズレの修正 | 「S3-2 が **R3**。D-0007 を差し戻す。選択肢から選び直したい」 |
| 前提が変わった | 「**R4**。G1 のKPIが変わった。影響するステップを全部洗い出して」 |
| 影響範囲を知りたい | 「S3-2 を変えると影響するカードIDを全部出して」 |
| 実測を反映したい | 「RUN-0007 の実測が出た。予測との差と、読み違いの原因を表にして」 |
| 市場を調べてほしい | 「〇〇を調べて、事実・出典・含意・影響ID・賞味期限の形で市場ノートに3行」 |
| 抽出会の準備 | 「今月の抽出会の材料をまとめて。昇格候補とメタKPIも」 |
| 委任を上げたい | 「S2-2 の委任レベルを上げてよいか、DoD達成履歴から判定して」 |

**型（R1〜R4）を口頭で言うだけで、AIが直す場所を間違えなくなります。** ここが一番のコツです。

## 5. やってはいけないこと

- ❌ AIに「全部いい感じにやって」と言う → 修正できない塊が返ってくる
- ❌ 選択肢を出させずにAIに決めさせる → 現場が使わない仕組みになる
- ❌ 「なんか違う」で終わらせる → うちらしさカードに1行足すまでがワンセット
- ❌ 完成条件（DoD）を書かないままステップを作る → 永遠に終わらない
- ❌ 1ファイルに全ステップを詰める → 修正のたびに全部読み直しになる
- ❌ **予測を書かずに実行する** → その回の学習はゼロで消える
- ❌ **層2（効かせる知識）を無制限に増やす** → AIが要点を見失い、逆に劣化する
- ❌ **1回のズレでルールを増やす** → 例外だらけになってAIが動けなくなる（3回ルール）
- ❌ 月次抽出会を飛ばす → ログが溜まるだけで、AIは何も学ばない
