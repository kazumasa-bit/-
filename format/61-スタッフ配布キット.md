# スタッフ配布キット（現場が触るのはこの3枚だけ）

> **フル版（カード11枚）をスタッフに配ってはいけません。確実に使われなくなります。**
> スタッフの負担は **起票10分＋週10分** が上限。これを超える設計にしたら配れません。
> 残りのカード（選択肢・補正係数・重み・抽出会など）は**管理者側が持ちます**。

---

## 配るもの・配らないもの

| | スタッフ | 管理者 |
|---|---|---|
| 困りごとシート | ✅ | ✅ |
| やることシート | ✅ | ✅ |
| ふりかえりシート | ✅ | ✅ |
| 選択肢カード（5軸採点） | ❌ AIが裏で使う | ✅ |
| 補正係数C・重みW・クセK | ❌ AIが裏で使う | ✅ |
| 決定ゲートの閾値設定 | ❌ | ✅ |
| 月次抽出会 | 一部参加 | ✅ 主催 |

**スタッフには「AIが賢くなる仕組み」を意識させません。** 裏で回ればいいものです。

# シート①：困りごとシート（起票 10分）

> 新しいテーマを始めるときに1回だけ書きます。

```
【名前】                【日付】

1. 何に困っていますか？（事実で）
   例）シフト作成に毎週4時間かかっている

2. それでどんな損をしていますか？
   例）店長の休みが取れない。作成が遅れて希望が通らずスタッフの不満が出る

3. 解決したら、月いくらの得ですか？（当てずっぽうでOK）
   □ 売上が上がる   月      円
   □ コストが下がる 月      円
   ☑ 時間が空く     月  16  時間 → 時給換算 約  4万  円
      └ 空いた時間で何をしますか？ 例）新人の同行指導に充てる

4. いつまでに解決したいですか？
   例）3ヶ月以内

5. 自分で決めていいこと／上長に聞くこと
   決めていい：シフトの組み方、使うツール
   聞く：お金がかかること、他店舗を巻き込むこと
```

**3が書けないテーマは起票しません。** 当てずっぽうで構いませんが、空欄は不可です。
（→ 詳しくは `62-利益接続表`）

# シート②：やることシート（週5分）

> AIがステップに分解して埋めてくれます。スタッフは**✓を付けるだけ**。

```
【テーマ】シフト作成の時間を半分にする      【今週】9/8〜9/14

  今週やること（3つまで）
  ☑ 1. 過去8週分のシフトを1つの表にまとめる       所要30分  9/9
  □ 2. 固定で入れる人・変動する人を分けて印を付ける  所要20分  9/11
  □ 3. AIに叩き台を作らせて、1週分だけ試す         所要30分  9/13

  合計 1時間20分  ← 週3時間を超えていたら、AIに減らしてもらう

  詰まったこと（あれば一言）
  →
```

**ルール：**
- 今週やることは**3つまで**（多いと必ず全部止まります）
- **合計が週3時間を超えたら減らす**（超えた計画は経験上ほぼ止まります）
- 各行に「動詞・所要時間・日付」が入っていること。入っていなければ計画ではありません

# シート③：ふりかえりシート（週5分）

> **これが AI を賢くする燃料です。** ここだけは飛ばさないでください。

```
【今週】9/8〜9/14

1. できた／できなかった
   ☑ できた  □ 半分  □ できなかった

2. 予測と実際
   予測：シフト作成が4時間 → 2.5時間になるはず
   実際：3.5時間だった
   ズレ：思ったより減らなかった

3. なぜズレた？（一言でOK。分からなければ「分からない」でOK）
   → 叩き台は早くできたが、個別の希望を反映する手戻りが多かった

4. 「なんか違う」と感じたところ（あれば）
   → AIの提案が、うちの「連勤させない」前提を無視していた
```

**4番が最重要です。** ここに書かれたことが、月次抽出会で**全社のAIに反映されます。**
「なんか違う」を書いてくれた人が、会社全体を賢くします。そう伝えて配ってください。

## ガードレール（スタッフのAIは、これを決めてはいけない）

以下は、AIが**案を出すことはできても、決定・実行はできない**設定にします。
該当したら自動的に🔴レーンとなり、上長に上がります。

- 金額 **30万円超**（閾値は自社で調整）
- 人事・処遇・評価に関わること
- 対外的な約束（お客様・取引先・応募者への条件提示）
- 法令・安全・衛生に関わること
- 他部署・他店舗を巻き込むこと
- 就業規則・シフトの法定要件に触れること

## 配り方（ここを間違えると全部無駄になります）

| # | やること | 理由 |
|---|---|---|
| 1 | **層2が育ってから配る**（失敗DB10件・補正3件が最低ライン） | 空のAIは一般論しか言わない。**「使えない」は1回で決まり、二度と覆せません** |
| 2 | **最初の1テーマは上長が横について一緒に起票する** | 1人で白紙に向かうと止まります |
| 3 | **2週間後に必ず声をかける** | 放置すると9割が止まります |
| 4 | **「ふりかえりを書いた人が会社を賢くしている」と伝える** | 作業ではなく貢献だと分かると続きます |
| 5 | **1人2テーマまで** | 増やすと全部止まります |

## 使われなくなる兆候（早期発見リスト）

| 兆候 | 意味 | 打ち手 |
|---|---|---|
| ふりかえりシートが空欄続き | 面倒か、書き方が分からない | 口頭で聞いて代筆する。書式を減らす |
| 「やること」が毎週同じで✓が付かない | 粒度が大きすぎる | AIに30分単位まで割らせる |
| 「なんか違う」が一度も出ない | 遠慮しているか、そもそも使っていない | 使用状況を確認。出してくれたら必ず反映して本人に伝える |
| 週の所要が20分を超える | 設計負けしている | シートを削る。管理者側に寄せる |
