# kazu_raport / 会社自動化

社内の課題を、AIと一緒に「一歩ずつ・選択肢を出させて・人が決めて・直しながら」
完成まで運ぶための**フォーマット一式**です。

## 考え方（3行）

1. 成果物を**カード**という小さな単位に割り、AIには**一度に1枚だけ**書かせる
2. AIは**決めない**。必ず3案＋5軸採点＋推奨を出し、**選ぶのはスタッフ**
3. 「なんか違う」は**4つの型（R1〜R4）**に分類し、直す場所を一意に決める

## カードの種類

| カード | 役割 |
|---|---|
| [北極星カード](format/10-北極星カード.md) | 課題・勝ち条件（KPI）・期限 |
| [うちらしさカード](format/11-うちらしさカード.md) | 自社の前提・価値観・**過去の失敗**・禁止事項 ★最重要 |
| [ステップカード](format/20-ステップカード.md) | 1作業単位。入力／出力／完成条件 |
| [選択肢カード](format/21-選択肢カード.md) | AIが出す3案＋5軸採点＋推奨 |
| [決定ログ](format/22-決定ログ.md) | 誰がいつどれを選び、なぜ選んだか |
| [修正ログ](format/23-修正ログ.md) | 何がズレて、どう直し、どこに影響したか |
