# ゴッドシール診断アプリ

生年月日・生まれた時間・5つの設問から、**診断 → 結果表示まで**その場で完結する単体HTMLアプリです。

- **ファイル**: `index.html` の 1 枚だけ。ビルド不要・サーバー不要・依存パッケージなし。
- **使い方**: ダブルクリックでブラウザが開けばそのまま動きます。
- **公開**: このリポジトリの Settings → Pages で `main` ブランチを指定すれば、そのまま公開URLになります。
- **埋め込み**: 既存サイトへは `<iframe src="index.html" style="width:100%;height:900px;border:0"></iframe>` で設置できます。

## 画面の流れ

```
表紙 → 生年月日・時間の入力 → 設問5問 → 演出（約3秒） → 結果
```

結果ページの構成:

| セクション | 内容 |
|---|---|
| CORE NUMBER | カバラ数秘のライフパスナンバー（1–9・11・22・33）と魂の型 |
| Ⅰ MARIA | 魂のシナリオ（CORE から決定） |
| Ⅱ FACE | 冒険の物語（太陽星座・エレメントから決定） |
| Ⅲ エネルギーバランス | 創造／直感／行動／調和／基盤 の5軸レーダーチャート |
| Ⅳ いまのあなたの卦 | 易経64卦（爻の図つき） |
| Ⅴ 才能と落とし穴 | 開いている扉／閉じやすい扉 |
| Ⅵ 処方箋 | 設問で選んだテーマ・現在の状態・推進力から生成 |

結果画面から **テキストコピー / 共有リンク発行 / 印刷・PDF保存 / 再診断** ができます。

## 判定ロジック

| 出力 | 算出方法 |
|---|---|
| CORE | 年・月・日をそれぞれ数字還元し合算、さらに還元（11・22・33 はマスターナンバーとして保持） |
| 太陽サイン | 生月日から12サインを判定（うるう年含め全日付をテスト済み） |
| エレメント | サインから 火・地・風・水 |
| 卦 | 生年月日＋生まれた時間＋5問の回答から 1〜64 を決定（同じ入力なら常に同じ結果） |
| 5軸スコア | CORE の基礎ベクトル＋エレメント補正＋設問の回答加算を 30〜100 に正規化 |

64卦のデータは**卦名と爻（陰陽6本）の組み合わせが全件一致することを検証済み**です。

## 中身の差し替え方

判定テーブルはすべて `index.html` 内の `<script>` 冒頭にまとまっています。
ここを書き換えるだけで、ロジック本体（`ENGINE` 以降）に触れずに内容を入れ替えられます。

| 定数 | 差し替えられる内容 |
|---|---|
| `AXES` | 5軸の名称 |
| `CORE` | CORE ごとの型名・キャッチ・MARIA本文・強み・落とし穴・鍵・色・相性数 |
| `SIGNS` / `ELEMENTS` | 12サインの FACE 本文・動き方・舞台／4エレメントの性質 |
| `HEX` | 易経64卦（`卦名｜キーワード｜爻(下→上,1=陽)｜メッセージ`） |
| `QUIZ` | 設問と選択肢（選択肢ごとに5軸への加算値を持つ） |
| `THEMES` / `STATES` / `AXIS_MSG` | 処方箋の本文パーツ |

たとえば設問を増やす場合は `QUIZ` に要素を足すだけで、進捗バー・戻るボタン・共有リンクの桁数まで自動で追従します。

## 共有リンクについて

`?d=1988-2-29&t=4:30&a=11111&n=さえり` のように、生年月日・時間・回答・名前をURLに載せて同じ結果を再現します。
入力値はブラウザの中だけで計算され、サーバーには一切送信されません（再訪問時の入力補完に `localStorage` を使用）。

## 注意

本アプリの判定は、**易経64卦・カバラ数秘・西洋占星術という公開された古典体系にもとづくオリジナル実装**です。
遺伝子デザイン研究所が提供する正式なゴッドシールの算出式そのものではありません。
公式の判定内容がある場合は、上記の差し替え表にしたがってデータを入れ替えてご利用ください。
