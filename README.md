# kazu_raport / 会社自動化

**社内のどんな課題でも、同じ手順で計画→実行→検証→改善まで運べるエンジン**です。
最終的に全スタッフに配り、**利益を最大化しながら、考える時間を減らす**ことを目的とします。

テーマは何でも構いません（採用・シフト・原価・教育…）。
`examples/` にある採用は、**このエンジンに入れる最初の1テーマの見本**にすぎません。

## 目的関数

> **利益を最大化しながら、人が考える時間を減らす。**
> どちらか一方だけを満たす提案は不合格。

## 考え方（9行）

**課題を完成まで運ぶ（docs/00）**
1. 成果物を**カード**という小さな単位に割り、AIには**一度に1枚だけ**書かせる
2. 重要な決定は人が決める。AIは判断材料を揃える
3. 「なんか違う」は**4つの型（R1〜R4）**に分類し、直す場所を一意に決める

**AI自体が進化する（docs/01）**
4. **予測を先に書かせ、実測と突き合わせる**。差分だけがAIを賢くする
5. AIの脳を**3層**に分け、**効かせる層は200行以内**に保つ（溜めるほど賢くなるは誤り）
6. **3回繰り返されたものだけ**をルールに昇格させる（月1回・60分の抽出会）

**エンジンにして配る（docs/02）**
7. **すべての決定に選択肢を出さない。**🟢自動 / 🟡承認 / 🔴熟考 に振り分ける
8. 前例が増えるほど🟢🟡に落ち、**使うほど考える時間が減る**（オートパイロット率）
9. **知識は全社で1つ、テーマは個人ごと。**だから人が増えるほどAIが賢くなる
