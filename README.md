# 🌱 畑ノート（自然農の畑管理ツール）

畑に植えたものを記録すると、**植えた日からの経過日数**をもとに「今の状況」と
**自然農での育て方・間引き方・相性の良い作物・土のアドバイス**が自動で出てくる、
スマホ向けのWebアプリです。神奈川県（温暖地）を想定しています。

## できること

- **記録**：植えた日 / 場所（区画） / 何を / 種か苗か を30秒で登録
- **今の状況**：経過日数から生育フェーズを判定し、その時期にやるべき作業を表示
- **図鑑**：作物ごとの自然農の育て方・間引き方・コンパニオンプランツ・ベストな土
- **土の診断**：畑に生えている草（指標草）から土の状態を推測し、自然農での調整方法を提案
- **AI相談**：データベースに無い作物は、状況を埋め込んだ質問文を生成してClaude等に貼れる
- **オフライン動作 / ホーム画面にインストール可能**（PWA）／データは端末内に保存（localStorage）

## 使い方

これは静的なWebアプリです。サーバーは不要ですが、サービスワーカー（オフライン機能）を
使うには `file://` ではなく HTTP で開く必要があります。

### すぐ試す（ローカル）
```bash
# このフォルダで簡易サーバーを起動
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

### スマホで常用する（GitHub Pages）
1. GitHub のリポジトリ設定 → **Pages** → Source を `main`（このブランチをマージ後）に設定
2. 公開URLをスマホで開き、ブラウザの「ホーム画面に追加」でインストール
3. 以降はアプリのように、オフラインでも畑で使えます

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・ロジック） |
| `crops.js` | 作物データベース＋指標草データ（ここを増やせば対応作物が増えます） |
| `manifest.json`, `sw.js`, `icon.svg` | PWA（インストール・オフライン）用 |

## 作物を追加する

`crops.js` の `CROPS` 配列に、既存の作物と同じ形式で追記するだけです。
`phases`（経過日数ごとの作業）を入れると、自動で状況判定に反映されます。

## 注意

生育日数や適期はあくまで**神奈川・温暖地の目安**で、その年の天候で前後します。
自然農は土地ごとに最適が変わるので、記録を続けてご自身の畑の“正解”を育ててください。
