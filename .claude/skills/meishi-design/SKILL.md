# 名刺デザイン

名刺は 91×55mm、手のひらにのる大きさしかない。それでも「この人は何者で、なぜ覚えておくべきか」を、一瞬で伝え、あとで連絡したいときに役に立つ紙でなければならない。
**情報の一覧表ではない。** 一人の人間を、いちばん強い一点に絞って見せる道具である。

この文書は3部に分かれる。
- A. 構成：何を載せるか
- B. デザイン：どう見せるか
- C. 進め方：どの順で作り、何を確かめてから出すか

---

## 0. 過去の失敗から学んだこと（必ず読む）

ダメだった名刺は、だいたい次の5つで失敗している。

1. **情報を全部載せた**：経歴、趣味、店名、URL を詰め込むと、どれも目に入らなくなる。「すべて」を伝えたいときは、全部を並べるのではなく、全部を一言で束ねる言葉や形を探す。
2. **Webの画面のように作った**：角丸の箱、タグ風の飾り、太い色帯、灰色の小さな見出し。これは画面の作法で、紙では安っぽく見える。
3. **コンセプトがなかった**：「すっきり」「和風」程度の方向性では、誰にでも当てはまる名刺になる。その人だけが持っている、具体的なものから発想する。
4. **文字の大きさを間違えた**：キャンバス上の px を、印刷したときの pt に換算していなかった。1mm＝10px のキャンバスで 16px は約 4.5pt で、読めない（B-4 の換算表を必ず使う）。
5. **方向性を一つに決め打ちした**：方向が決まっていないうちに、完成品を1案だけ作った。先に、性格のはっきり違う案を複数見せる（C-3）。
6. **画像で確かめずに出した**：一度も見ずに出したので、ダサさに気づけなかった。点検ツールで画像にして、自分の目で見てから出す（C-5）。
   - 2026年11月、前回の表面を点検した結果：文字は4.0〜4.5pt で、5種類の大きさと3つの書体が混ざり、9件の不合格だった。
   - 見た目も、テンプレートのような汎用の顔で、角丸の印はアプリのアイコンに見えた。

## A. 構成：何を載せるか

### A-1. 最初に決める3つの問い

作り始める前に、次の3つに答えを出す。答えのないまま作ると、必ず全部載せになる。

| 問い | 例 |
|---|---|
| 誰に渡すか | 取引先の業者、お客様、銀行、近所の人、海外の取引先 |
| 渡したあと、相手にどうしてほしいか | 電話してほしい、店に来てほしい、名前を覚えてほしい、検索してほしい |
| 1年後、相手の机に残っていたとき、何を思い出してほしいか | 「あのクルマの人」「仕組みを作る社長」「千代の古民家の人」 |

3つ目の答えが、この名刺の **コンセプト** になる。

### A-2. 情報を3つに仕分ける

候補を全部書き出してから、次の3つに分ける。

- **必須**（これがないと名刺として役に立たない）：氏名、連絡の入口1つ（電話かメール）、何者かを示す一言
- **選択**（目的に合うときだけ載せる）：ふりがな／ローマ字、住所、2つ目の連絡先、URL かQRコード、肩書き
- **載せない**：趣味の羅列、売上などの数字、経歴の全部、SNS の全部、キャッチコピーの決まり文句（「お客様第一」「笑顔をお届け」など）

表面に載せる要素は、**7つまで** を目安にする。それより多いときは、裏面に回すか、捨てる。

### A-3. 見せる順番は4段階まで

| 段階 | 中身 | 見え方 |
|---|---|---|
| L1 | 氏名、またはその人を表す一つの印 | いちばん大きく、最初に目に入る |
| L2 | 何者かを示す一言（肩書きや屋号） | L1 の次に読まれる |
| L3 | 連絡先（住所・電話・メール・URL） | 必要になったときに探して読む |
| L4 | 補足（ローマ字、郵便番号、細かい注記） | ほとんど読まれない |

**文字の大きさは3種類まで** に絞る。段階の差は、大きさより、太さ・間隔・位置・色の濃さで付けるほうが上品になる。

### A-4. 肩書きがたくさんある人の名刺（複数の会社や店を持つ人）

「全部の顔を1枚にしたい」という依頼は、次の4つの型から選ぶ。並べるだけの型はない。

1. **人そのものを看板にする型**
   - 表に名前と、その人を表す印だけを置き、会社や店の名前は出さない。
   - 裏で、関わっている事業を目次のように控えめに並べる。
   - 「この人に会えば、全部につながる」と伝わる。
2. **目次の型**
   - 裏面を、事業の一覧としてきちんと組む。
   - 項目は同じ形式で揃え、余計な説明は付けない。
   - 最大で6項目程度。
3. **家族の型**
   - 共通の設計（同じ書体・同じ格子・同じ紙）で、事業ごとに1枚ずつ作る。
   - 色や一語だけを変えて、同じ人の名刺だとわかるようにする。
   - 場面に合わせて渡し分けられる。いちばん実用的。
4. **二つ折り・二枚重ねの型**
   - 開くと全体が見える。
   - 印象は強いが、費用が高く、名刺入れに入りにくい。

### A-5. 日本の名刺ならではの決まり

- **氏名**：姓と名の間に、全角の半分程度のアキを入れる（スペースを2つ入れて代用しない）。ふりがなは、名前より十分小さく、字間を広げる。
- **住所**：郵便番号は「〒」を付けて、住所の前か上に置く。番地は、郵便が届く書き方（住居表示）で書く。登記上の地番（例：「105番3」）が郵便の宛先と同じかどうかは、必ず確かめる。
- **電話番号**：市外局番をハイフンで区切る。数字は、欧文の書体で組むほうが読みやすい。
- **メールとURL**：「https://」と、末尾の「/」は書かない。長いときは QR コードにする（一辺15mm以上）。
- **縦組み**：和の格を出すときに強い。ただし欧文と数字の扱いが難しいので、腕が必要になる。

## B. デザイン：どう見せるか

### B-1. コンセプトを一点に決める

- その人だけが持つ具体的なものから、**一つだけ** 発想の種を選ぶ。
  - 例：使っている素材、印にできる漢字、仕事の道具、建物、色の由来
- 選んだ種を、飾りとして描くのではなく、**構成の原理** にする。
  - 例：格子の比率、余白の取り方、紙の選び方、加工の位置
- 「この名刺の、覚えてもらう一点は何か」を、一文で言えないなら、まだ作り始めない。

### B-1.5. 余白は「何もない所」ではなく「受け止める器」（原研哉の考え方）
- 原研哉は、余白を「シンプル」や「ミニマル」とは区別した。余白は、見る人の想像や意味が流れ込む器（エンプティネス）だと考えた。
- 名刺に置き換えると、こうなる。
  - 削るのは、ただ少なく見せるためではない。受け取った人が「この人は何者だろう」と思い、会話が生まれる余地を残すためである。
  - 全部を書き切った名刺は、その余地を消してしまう。
- **日本の「間」**：要素と要素の距離そのものが、意味を持つ。距離は何となく決めず、格子の数字で決める。

### B-2. 格子と余白

- **仕上がりサイズ**：91×55mm。
- **安全域**：文字は、断裁線から3mm以上内側に置く（印刷の最低条件）。デザインとしては5〜6mm内側を標準にする。
- **揃える線は2〜3本まで**：左端、ベースライン、右端など。線の数を増やすと散らかる。
- **余白は残り物ではない**：大きく空ける場所を、先に決める。要素は端か角に寄せ、中央に何となく置かない。
- **全部を中央揃えにしない**：中央揃えは、要素が2つ以下のときだけ使う。
- **非対称の緊張感**：重いもの（名前）と軽いもの（連絡先）を対角に置くと、紙の上に動きが出る。

### B-3. 書体

- **書体は2つまで**：和文1つ＋欧文1つが基本。3つめは使わない。
- **和文**
  - 明朝体：格と静けさ。Shippori Mincho、Zen Old Mincho、Noto Serif JP、本格的には游明朝や秀英明朝。
  - ゴシック体：明快さと現代性。Zen Kaku Gothic New、Noto Sans JP、本格的には游ゴシックや AXIS。
- **欧文**
  - 骨格の美しいもの。セリフ体なら Cormorant、EB Garamond。サンセリフ体なら Inter、Söhne 系。
  - 和文と並べるとき（和欧混植）は、欧文を5〜10%大きくし、ベースラインを揃える。
- **字間**：小さい文字ほど、少し広げる（和文の小さい文字で +50〜100）。大きな名前は、詰めすぎない。
- **偽の太字は使わない**：太さは、書体に用意されたウェイトで変える。
- **数字**：電話番号は、等幅の数字か、落ち着いた欧文の数字で組む。

### B-4. 文字の大きさ（キャンバスの換算表）

キャンバスは **1mm＝10px**（名刺は 910×550px）で描く。1pt＝0.3528mm なので、**1pt ≒ 3.5px** になる。

| 用途 | 印刷の大きさ | キャンバスの px |
|---|---|---|
| 最小（補足・ローマ字） | 6〜6.5pt | 21〜23px |
| 連絡先・住所 | 7〜8pt | 25〜28px |
| 肩書き | 8〜9pt | 28〜32px |
| 氏名 | 12〜18pt | 42〜64px |
| 印・大きな見せ場 | 自由 | 自由 |

**6pt（21px）より小さい文字は使わない。** 線の太さは 0.25pt（約1px）以上にする。

### B-5. 色

- **基本は紙の色＋インク1色**。2色めは、意味があるときだけ足す。
- 色は「たくさん」ではなく、**一色を正しく選ぶ** ことに力を使う。印刷では、特色（DIC や PANTONE）で指定すると、品が出る。
- 文字は、黒の単色（K100）で刷る。広い面を濃く塗るときは、複数のインクを重ねた黒（リッチブラック）を使う。
- 灰色の文字は、薄くしすぎない。紙の上で読めないと意味がない。
- **白黒にしても、見せたい順番がわかる** ことを確かめる。

### B-6. 紙と加工（名刺の半分は紙で決まる）

- **厚み**：0.3mm以上だと上質に感じる。0.5mm以上なら、存在感が出る。
- **紙**：手触りのある紙（ヴァンヌーボ、コットン紙、竹尾の GA 系など）。艶のない紙は、文字が読みやすく、格が出る。
- **加工は、コンセプトと結び付いたときだけ使う**
  - 活版印刷：文字が凹み、手仕事の気配が出る。
  - 箔押し：金・銅・黒の箔。印や名前の一点にだけ使う。
  - 空押し：インクを使わない凹凸。静かな上質さが出る。
  - 小口染め：紙の側面に色を付ける。
- 画面のデザインで、紙と加工を再現しようとしない。仕様として書き添え、画面では平らな色で示す。

### B-7. ダサくなる原因（見つけたら直す）

- 全部が中央揃え
- 文字の大きさが4種類以上ある
- 飾りの線、枠、角丸の箱、帯
- 電話・メールの横の小さなアイコン
- グラデーション、影、光沢、絵文字
- 色が3色以上ある
- 書体を縦や横に引き伸ばしている
- フリー素材っぽいロゴ、意味のないマーク
- 決まり文句のキャッチコピー
- 趣味・経歴・数字の羅列
- 端まで文字が詰まっていて、余白がない
- 小さすぎて読めない文字

## C. 進め方

### C-1. 聞き取りと材料集め
- 接続しているツール（Drive・Gmail・Notion など）で、本人の情報を先に集める。
  - 過去の名刺、会社や店の情報、住所、ロゴ、好きなもの、すでに決めている色や素材
- 集めて分からないことだけを、本人に聞く。

### C-2. 構成案を先に決める（デザインより先）
- A-1 の3つの問いへの答え、A-2 の仕分け、A-4 で選んだ型を、短い表にして本人に見せる。
- **ここで合意できるまで、デザインに入らない。**

### C-3. 方向性の案を3〜4つ並べる
- 性格がはっきり違う案を並べる。
  - 例：「静かな明朝の余白」「強いゴシックの一語」「印を主役にする」「縦組み」
- 各案に、どこが違うかを表す名前を付ける。
- 細部は作り込まず、骨格（配置・書体・色）で比べられれば十分。
- 案ごとの長所と弱点は、画面の中ではなく、返事の文章に書く。

### C-4. 選んだ案を仕上げる
- 実寸の比率（910×550px）で、表と裏を作る。
- B-4 の文字の大きさの表を守る。
- 紙と加工の仕様を書き添える。

### C-5. 画像にして自分の目で見る（省略しない）
次のコマンドで点検ツールを動かす。
```
NODE_PATH=$(npm root -g) node .claude/skills/meishi-design/check-card.js <名刺のHTML> <出力フォルダ>
```
- **機械で点検すること**：6pt未満の文字、安全域（端から5mm）からのはみ出し、文字の大きさが4種類以上、書体が3つ以上、読み込めていない書体。
- **書き出される画像**：拡大画像、実寸に近い画像、白黒画像の3つ。
- **人の目で見ること**：書き出された実寸画像を Read で開き、自分の目で見る。そのうえで C-6 の自己批評をする。
- **直すことが1件でもあれば、見せる前に直す。**
- 画面を見て「テンプレートっぽい」「どこかで見た」と感じたら、コンセプトに戻る。

### C-6. 出す前の自己批評（全部「はい」になるまで出さない）
1. **1秒で何がわかるか**：一瞬見て、名前とその人が何者かがわかるか。
2. **目を細めて見る**：大きな形の配置だけで、見る順番がわかるか。
3. **一つ減らす**：もう一つ削れる要素がないか。
4. **実寸で見る**：91×55mm に縮めて、いちばん小さい文字が読めるか。
5. **白黒で見る**：色を抜いても、見せたい順番が保たれているか。
6. **ダサい原因**：B-7 の一覧に、一つも当てはまらないか。
7. **コンセプト**：この名刺の覚えてもらう一点を、一文で言えるか。

### C-7. 入稿データにする
- **データの大きさ**：仕上がり 91×55mm に、塗り足し 3mm を四方に付ける（97×61mm）。
- **安全域**：文字は、仕上がり線から 3mm 以上内側に置く。
- **色の形式**：CMYK、または特色で指定する。
- **画像**：350dpi 以上。
- **文字**：アウトライン化する（文字を図形に変換する）。
- **最小サイズ**：文字 6pt、線 0.25pt。
- 最後は、印刷所ごとの入稿ガイドに合わせる。
