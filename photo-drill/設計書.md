# 写真ドリル 設計書（販売用アプリ講座）

## 1. 何を売るか

iPhoneで**実際に試しながら覚える**練習アプリ。読むだけ・動画を見るだけの講座と違い、1ミッションずつ「やってみる → できた」で進むので、手が覚える。

| 決めたこと | 内容 |
|-----------|------|
| 形 | Webアプリ（リンクで開き、ホーム画面に追加するとアプリのように使える。オフラインでも動く） |
| 料金 | 無料体験（最初の2章）＋ 買い切りで残りを解放 |
| 版（ターゲット別） | ① おいしい写真ドリル（カフェ・料理好きの女性） ② こども写真ドリル（子育て中のママ・パパ） |
| 見本 | 自分で撮ったビフォーアフター写真を各ミッションに入れる |

> 名前について：Appleの商標の関係で、商品名の頭に「iPhone」を付けるのは避けるのが無難です（「iPhoneで撮る」「for iPhone」のような説明での使用はOK）。名前はあとで変えられます。

## 2. 仕組み

```
src/
  template.html      画面の骨組み
  style.css          見た目（版ごとに色だけ変わる）
  engine.js          アプリ本体（全版共通）
  content/
    cafe.js          おいしい写真ドリルのミッション・設定
    mama.js          こども写真ドリルのミッション・設定
build.py             版ごとに1つのアプリへまとめる
dist/
  cafe/  index.html, manifest.webmanifest, sw.js, icon.svg, photos/
  mama/  （同じ）
photos/
  cafe/  見本写真を入れる場所（撮影リスト参照）
  mama/
```

- **新しい版を作る＝ `content/` にファイルを1つ足すだけ**。エンジンは共通なので、直したバグは全版に反映される
- 版ごとの設定：名前、キャッチコピー、テーマ色、無料の章数、価格、購入ページのURL、購入コード

### 画面
1. **ホーム**：進み具合、次のミッション、章の一覧（有料の章は鍵マーク）
2. **ミッション**：なぜ覚える？／手順／見本写真（ビフォー・アフター）／できた目安／コツ／自分メモ／「できた！」
3. **購入**：有料の章を押すと出る。価格・中身・購入ボタン・「購入コードを入力」
4. **修了**：全部できたら修了画面

### 進み具合の保存
- その端末（ブラウザ）に保存。アカウント登録なしで始められる
- 機種変更対策は v2 で（アカウント・クラウド保存）

### 購入とロック解除（v1）
1. 購入ボタン → 決済ページ（Stripeの「Payment Links」やSTORES、BASEなど）
2. 支払い完了ページ／メールに**購入コード**を表示
3. アプリで購入コードを入力 → 残りの章が開く

v1の注意：コードは全購入者共通で、アプリ側でチェックする簡易方式です。詳しい人ならコードを共有したり回避したりできます。最初の販売テストには十分ですが、売れ始めたら v2 で「購入者ごとのコード（ライセンスキー）」をサーバーで確認する方式に変えます（Lemon Squeezy や Stripe＋小さなサーバーで可能）。

## 3. 版ごとの中身

| 章 | おいしい写真ドリル | こども写真ドリル |
|----|------------------|----------------|
| 1（無料） | 最初にやる設定 | 最初にやる設定 |
| 2（無料） | ピントと明るさ | 動く子どもを逃さない |
| 3 | 2倍で撮る・レンズの使い分け | 子どもが一番かわいく写る角度と光 |
| 4 | 料理のアングルと構図 | 寝顔・室内・暗い場所 |
| 5 | 光とスタイリング | 運動会 |
| 6 | 動きと湯気（Live Photos） | 発表会・入学式 |
| 7 | 色レシピと編集 | 成長記録と家族写真 |
| 8 | インスタ投稿の仕上げ | 整理・共有・SNSの安全 |

## 4. リリースまでの流れ

1. 試用版を自分で全部やる（＝講師としての練習も兼ねる）
2. 見本写真を撮って `photos/` に入れる（撮影リスト参照）
3. 名前・価格を決める
4. 決済ページを作り、URLと購入コードを `content/` に入れて `build.py` を実行
5. 公開（Netlify / Cloudflare Pages / GitHub Pages、どれも無料から）
6. 販売ページ＋特定商取引法の表記
7. モニター5人に無料で使ってもらい、感想をもらう → 販売開始

詳しくは `リリース手順.md`。
