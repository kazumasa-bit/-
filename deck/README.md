# 達成の6原則 — RAPORT メソッド（60分プレゼン資料）

個人向けコンサル／コーチングで、自分の達成理論を体系として提示するための登壇資料。

## ファイル

| ファイル | 内容 |
|---|---|
| `達成の6原則_RAPORTメソッド.pptx` | 本編 58枚（講師ノート付き） |
| `build.js` | 資料を生成する pptxgenjs スクリプト |
| `qa_layout.py` | レイアウト検査（文字あふれ・枠外・テキスト重なり） |

## 構成

RAPORT の6文字＝6原則。

| | 原則 | 内容 |
|---|---|---|
| R | Reverse | 目標から逆算する |
| A | Analyze | 現在地を知る（マーケティング思考 12ステップ） |
| P | PDCA | 回す |
| O | Overcome | 失敗を越える |
| R | Reframe | 解釈を変える（人には適切なことしか起こらない） |
| T | Trust | 有益性のバランス／Win-Win |

## 登壇前に必ず記入する箇所

`【　】` で囲まれた箇所が記入欄。

1. 表紙（講師名・肩書）
2. 自己紹介と実績の数字
3. 実践者の変化（3事例）
4. 伴走メニューの価格
5. 最終ページの連絡先

## 時間配分

全スライドのノートに `【mm:ss–mm:ss】` で時間が入っている（合計 60:00、Q&A 別途8分）。
`【60分版では省略】` と書かれた7枚を飛ばすと 60分に収まる。全部投影すると約75分。
巻末に 30/45/60/75/90分 の構成ガイドあり（講師用・投影しない）。

## 再生成

```bash
npm install pptxgenjs
node build.js 達成の6原則_RAPORTメソッド.pptx
python3 qa_layout.py 達成の6原則_RAPORTメソッド.pptx
```
